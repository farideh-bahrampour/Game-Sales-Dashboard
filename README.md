# 🎮 Game Sales Dashboard

## 📌 Project Overview
This project is an interactive dashboard created using **Tableau Public** to explore video game sales across different regions, genres, platforms, and years.

## 📊 Dashboard Features
- Compare game sales in **Europe, North America, Japan, and globally**.
- Explore the most popular game genres.
- Analyze sales across different gaming platforms.
- Visualize game sales trends from 1980 to 2020.
- Use interactive charts to explore the data.

## 🛠️ Tools Used
- Tableau Public
- Data Visualization
- Data Analysis

## 🔗 Live Dashboard
[View Game Sales Dashboard on Tableau Public](https://public.tableau.com/app/profile/farideh.bahrampour/viz/GameSalesDashboard_17792633443880/EU)

## 🎯 Project Goal
The goal of this project is to practice data visualization and create an interactive dashboard that makes video game sales data easier to understand and compare.
